# Web Interface Guidelines (Vercel)

Prüfe die angegebenen Dateien (Standard in diesem Projekt: `index.html`, `style.css`, `app.js`) gegen alle Regeln in [guidelines.md](guidelines.md) und gib die Befunde im dort beschriebenen `file:line`-Format aus.

Hinweise für dieses Projekt:
- Reines HTML/CSS/JS ohne Framework – Regeln zu React/Hydration entfallen.
- Das Designsystem steht in `DESIGN.md`; bewusste Ausnahmen (z. B. Federn, Liquid-Glass-Schatten) sind dort begründet und keine Befunde.
- Deutsche Oberfläche: Anführungszeichen „…“, Auslassungszeichen …, Zahlen/Daten mit `de-DE`.
